Une action est une requête HTTP. Exécutée par le hub pour une API externe, ou par l'agent d'un appareil pour joindre un sous-appareil sur son réseau local (par exemple l'API HTTP d'un processeur LED). Les actions servent aux boutons du tableau de bord et aux automatisations.
