Une action est une requête HTTP. Exécutée par le hub pour une API externe, ou par l'agent d'un écran pour joindre un appareil sur son réseau local (par exemple l'API HTTP du Tessera). Les actions servent aux boutons du tableau de bord et aux automatisations.
